    Detailed Description¶

    Detailed tool-call event carrying the full owning FTryllToolCall value object (node name and disposition included) alongside the agent id. Fired in addition to — never instead of — OnToolCall / OnToolCallWithId, so a manual handler can tell whether to send results for await_result or plain-resume for other pausing dispositions. ClassifyIntentLLM — event_type="intent_llm_classified". Subscribing swallows OnNodeEvent. Pause typed event — fired for NodeEvent event_type="paused" (the executor paused the turn between nodes; ChangeAgentParam is allowed while paused). Generic NodeEvent fallback — fired for any event_type without a typed delegate (or when the typed delegate has no subscribers). KvPairs preserves wire order. Game-instance subsystem: one TCP session to the Tryll server. Manages the socket connection on a background thread (FTryllConnection) and drains the event queue on Tick(), dispatching to registered agents and delegates.

    Default (zero-wiring) path — driven by UTryllRuntimeSettings: * bAutoLaunchServer → spawns the bundled tryll_server.exe on Initialize. * bAutoConnect → Connect() on Initialize (connect-retry covers server startup). * bAutoCreateSession → on Connected, CreateSessionFromSettings() sends the game name, locale and the manifest-derived engine hint. UTryllAgentComponent / UTryllVoiceInputComponent then create themselves once IsSessionReady() — they queue until OnCreateSessionComplete if they spawn earlier. So the common case is: download models in the Model Manager, add the components, press play. There is no engine to pick: each model's catalog entry names it.

    Manual path — turn those flags off to drive the session yourself: * Connect() — open TCP session to ServerHost:ServerPort. * OnConnectionChanged(bConnected=true) — bind to continue; or poll IsConnected(). * CreateSession(GameName, Locale) — configure explicitly (overrides settings). Completion arrives on OnCreateSessionComplete; IsSessionReady() is true thereafter. * CreateAgent — attach a UTryllAgentComponent (auto-creates once the session is ready) or call RequestCreateAgent(). * SendMessage(Text) — drive one turn; chunks on OnAnswerText, the turn ends with OnTurnComplete(Status). * RequestDestroyAgent / Disconnect — tear down when done.

    All delegates fire on the game thread from Tick(); it is safe to touch UObjects and UI directly from callbacks.

    variable OnLocalizedTextApplied¶

    FOnTryllLocalizedTextApplied UTryllSubsystem::OnLocalizedTextApplied;

    A language change reached a live agent: the server acknowledged every Localized prompt that changed, or none needed to change. Wait for this before work that must see the new prompts, such as a KV prefill. An AgentBusy reply delays it until the running turn ends.

    variable OnLocalizedTextFailed¶

    FOnTryllLocalizedTextFailed UTryllSubsystem::OnLocalizedTextFailed;

    A language change could not update a live agent's Localized prompts: a Text ID is empty or missing in the new language. Nothing was sent to that agent, so it keeps every prompt in the previous language (voice and {{language}} already follow the new one). Fix the table, or recreate the agent.

    Public Functions Documentation¶

    function Connect¶

    void UTryllSubsystem::Connect ()

    Open a TCP session to ServerHost:ServerPort. Asynchronous — completion is reported via OnConnectionChanged(bConnected=true). Errors fire OnError. Calling Connect() while already connected is a no-op.

    function CreateSession¶

    void UTryllSubsystem::CreateSession (
    FString GameName=TEXT(""),
    FString Locale=TEXT(""),
    bool bUseProjectLocaleWhenEmpty=true
)

    Send CreateSessionRequest. Must be called after Connected and before CreateAgent. Result is delivered via OnCreateSessionComplete delegate.

    Parameters:

    • GameName Integration identifier for telemetry grouping (e.g. "tryll-roleplay-demo"). Leave empty to omit; the server defaults to the project name, then "unknown", when telemetry is on. Pass UTryllRuntimeSettings::GameName to drive this from the project settings asset.
    • Locale Session language as a BCP-47 tag (e.g. "de", "pt-BR"). See UTryllRuntimeSettings::Locale for everything it drives. Empty uses the project setting unless bUseProjectLocaleWhenEmpty is false; a malformed tag is rejected with InvalidLocale (2004).
    • bUseProjectLocaleWhenEmpty When true, an empty Locale adopts the text provider's current language, then UTryllRuntimeSettings::Locale. Set false with an empty Locale to explicitly disable session language. The four engine parameters this took through protocol v12 are gone. The engine set is derived from the models registered in UTryllModelManifest — each model's catalog entry already states which engine runs it, so there is nothing for a caller to choose, and nothing that can drift out of step with the models the project references.

    Storage root is process-wide (set when the server launches via storage-root), not per session — protocol v24 removed CreateSessionRequest.storage_data_folder.

    function CreateSessionFromSettings¶

    void UTryllSubsystem::CreateSessionFromSettings ()

    function SetSessionLocale¶

    void UTryllSubsystem::SetSessionLocale (
    FString Locale
)

    Change the session language without tearing the session down. Pass an empty Locale to clear it.

    Applies to every agent, existing and future, from its next turn: TTS language and the locale template keys are read per turn, not captured at agent creation. A new voice input picks up the new STT language hint; one already open keeps its recognizer. Storage paths re-resolve on the next load, but content already bound to a node (a Retrieve KB, canned lines) does NOT swap - those params are structural, so switching authored content still means recreating agents.

    Not turn-atomic: a turn already running may render its prompt under the old locale and synthesize under the new one.

    Completion is broadcast via OnSetSessionLocaleComplete.
