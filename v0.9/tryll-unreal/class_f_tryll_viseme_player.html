    Detailed Description¶

    Plays a TTS viseme track as ARKit curve values, in step with audio playback.

    Engine-object free so any consumer can drive it: UTryllLipSyncComponent writes the curves to morph targets, and a MetaHuman integration can push the same curves through Epic's ARKit mapping.

    Per turn: BeginTurn (from UTryllSpeakerComponent::OnTtsTurnStarted), then AddEvents for each viseme frame (OnTtsVisemes). Every frame: Tick with the playback clock's played samples, then read GetCurves().

    What it does, as in the Unity client's TryllLipSync: * the active viseme's pose, scaled by the event weight (loudness); * a smoothstep cross-fade over AttackDecayMs into each new viseme; * Intensity scales everything; * exponential smoothing at SmoothingPerSecond, ClosureSmoothingPerSecond while p/b/m or f/v is showing (a ~70 ms closure never lands at the slow rate); * the track is read ahead by the delay that smoothing adds, so tuning it does not move sync; * rest once the last shape of a turn has been held MaxHoldMs.
