# Blueprint Catalog

The Blueprint-visible nodes exposed by the Tryll Unreal plugin, grouped by category. Use this page to find *which* Blueprint function or event to place; use the [Unreal C++ API Reference](https://docs.tryllengine.com/v0.9/reference/client-api/unreal/cpp/index.html) and the [feature reference pages](https://docs.tryllengine.com/v0.9/reference/index.html) for parameter-level detail.

Most nodes live under two UObjects; the speaker, lip-sync and voice-input components add their own (below):

- **`UTryllSubsystem`** — a `UGameInstanceSubsystem`. Access from any Blueprint with the `Get Tryll Subsystem` node (`GameplayStatics → GetGameInstance → GetSubsystem<TryllSubsystem>`).
- **`UTryllAgentComponent`** — an `UActorComponent`. Add one to any actor; when `bAutoCreateOnConnect` is `true` (the default), it auto-creates its agent once the session is ready (connected **and** the session created), queuing if it spawns earlier. (The property name predates the session-ready semantics.)

Static helper libraries (`Tryll|Languages`, `Tryll|Intent`), the `UTryllKvResidencyPolicy` component (`Tryll|KV Cache`), and the generated node-params factory are not listed here; see their class pages.

Categories use the pipe convention (`Tryll|Connection`, `Tryll|Models`, …) so everything appears grouped under a single **Tryll** folder in the Blueprint context menu.

## Voice — `Tryll|TTS` (on `UTryllAgentComponent`)

The agent's voice is a [voice profile](https://docs.tryllengine.com/v0.9/reference/voice-profile.html): a `UTryllVoiceProfile` data asset (Content Browser **Tryll ▸ Voice Profile**) assigned to the component's **Voice Profile** property (`Tryll|TTS`, editable, Blueprint read-only). Every speaking node of the workflow (Speak, Generate And Speak) uses it. A workflow that speaks needs one: without it the server refuses the agent with `AgentVoiceRequired` (3025), the component logs an error at **Create Agent**, and Data Validation flags the component. One workflow can serve many characters, each with its own profile.

The component's **Voice Delivery** row is a per-agent override of the profile's default mode. Enable its checkbox and choose neutral or one of the assigned profile's modes. It is used by the next **Create Agent** without modifying the shared profile asset, and a change applies immediately to a live PIE or Tryll Chat agent.

| Node                  | Kind     | Inputs                                                           | Outputs   | Notes                                                                                                                                                                                                                                                                                                                                                                                                                    |
| --------------------- | -------- | ---------------------------------------------------------------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Set Voice**         | Callable | `New Voice` (`UTryllVoiceProfile`)                               | —         | With a live agent, replaces its voice (idle only: `AgentBusy` 3004 during a turn; `InvalidVoiceProfile` 3023 when the model cannot use the profile, and the old voice stays) and assigns **Voice Profile** on success. The active delivery mode survives when the new profile defines a mode of the same name. Without an agent it only assigns **Voice Profile** for the next **Create Agent**. Fires `OnVoiceChanged`. |
| **Set Delivery Mode** | Callable | `Mode` (`FString`), `Intensity` (`float`, default `1`, advanced) | —         | Switches the voice's delivery mode, for example `angry`. Allowed mid-turn; applies from the next sentence. `neutral` always works; a mode the profile does not define fails with `UnknownDeliveryMode` (3024) and the current mode stays. `Intensity` (0–1) scales the mode where the model can use it. Fires `OnDeliveryModeChanged`.                                                                                   |
| **Get Delivery Mode** | Pure     | —                                                                | `FString` | The mode last applied to the live agent; the profile's default mode (empty = `neutral`) before any switch.                                                                                                                                                                                                                                                                                                               |

| Event                        | Payload                                     | Fires when                                                                                                                         |
| ---------------------------- | ------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| **On Voice Changed**         | `Error` (`FTryllError`)                     | **Set Voice** completed. `Error.Code` is `0` on success.                                                                           |
| **On Delivery Mode Changed** | `Mode` (`FString`), `Error` (`FTryllError`) | **Set Delivery Mode** completed. `Error.Code` is `0` on success, `3024` for an undefined mode, `3025` when the agent has no voice. |

## Events — `Tryll|TTS` (on `UTryllSpeakerComponent`)

`UTryllAgentComponent` plays TTS audio through the `UTryllSpeakerComponent` on its actor, and adds one at `CreateAgent` if the graph speaks and there is none. Add one yourself to bind these events to react to the audio lifecycle. Every Started is followed by exactly one Finished (unless the component ends play mid-speech). The agent's **Speaker** property (`Tryll|TTS`, Blueprint read/write, set on a placed instance) picks a specific speaker; it is read at `CreateAgent`.

| Event                     | Payload | Fires when                                                                                                                                                                                        |
| ------------------------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **On Tts Audio Started**  | —       | The first PCM chunk of a turn is queued — speech is about to begin. Once per turn, even when several nodes speak.                                                                                 |
| **On Tts Audio Finished** | —       | The turn is complete and its queued audio has been handed to the audio engine (its own buffers, a few tens of ms, still play out). Also fires immediately when **Stop Playback** cuts speech off. |

| Function                  | Kind     | Returns | Description                                                                                                                                                                                                                                        |
| ------------------------- | -------- | ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Stop Playback**         | Callable | —       | Drops all queued audio and ignores further audio until the next turn announces its audio format. Fires **On Tts Audio Finished** if speech was playing. Does not cancel the turn — call **Cancel** on the agent for that. Safe to call repeatedly. |
| **Get Sample Rate**       | Pure     | `int32` | Sample rate of the current TTS stream, in Hz. `0` before the first format announcement.                                                                                                                                                            |
| **Get Output Latency Ms** | Pure     | `float` | Audio engine output buffering after the speaker's playback clock, in milliseconds. `0` without an audio device. Tryll Lip Sync subtracts it when **Compensate Output Latency** is on.                                                              |

See [Add Voice Output to an Agent](https://docs.tryllengine.com/v0.9/how-to/add-voice-to-an-agent.html) for the full setup workflow.

For most graphs you don't need them at all: pin a storage by relative path in the node's params and the server loads it at agent-creation time. See [String Storage](https://docs.tryllengine.com/v0.9/reference/string-storage.html) and [Embedded String Storage](https://docs.tryllengine.com/v0.9/reference/embedded-string-storage.html).

## Typical Blueprint flows

**First inference** — bind `OnConnectionChanged` on the subsystem, call `CreateSession` on `bConnected=true`, wait for `OnCreateSessionComplete`, then call `CreateAgent` on the component. See [First Inference in Unreal](https://docs.tryllengine.com/v0.9/getting-started/first-inference-unreal.html).

**Streaming a reply** — bind `OnAnswerText` on the agent component, append `Text` to your UI widget on each event, show the "done" state on `OnTurnComplete`. See [Stream Answers to UI](https://docs.tryllengine.com/v0.9/how-to/stream-answers-to-ui.html).

**Handling a tool call** — bind `OnToolCall` on the agent component, parse `ArgumentsJson`, run your game-side logic. The subsystem event is the all-agents form. See [Define and Handle Tool Calls](https://docs.tryllengine.com/v0.9/how-to/define-and-handle-tool-calls.html).

**Speaking NPC** — add `UTryllSpeakerComponent` to the actor alongside `UTryllAgentComponent`. Download a TTS model in the Model Manager. Use a `UTryllWorkflowAsset` with a **GenerateAndSpeak** (or **Speak**) node, create a **Voice Profile** asset that names the TTS model, and assign it to the agent component's **Voice Profile**. Call **Set Delivery Mode** to make the character sound angry or calm. For mouth movement, add **Tryll Lip Sync** and turn on **Emit Visemes** in the voice profile (see [Add Lip Sync to a Character](https://docs.tryllengine.com/v0.9/how-to/add-lip-sync-to-a-character.html)). Bind **On Tts Audio Started** / **On Tts Audio Finished** on the speaker component for other reactions, and call **Stop Playback** on it to cut the NPC off. See [Add Voice Output to an Agent](https://docs.tryllengine.com/v0.9/how-to/add-voice-to-an-agent.html).

**Prepare an NPC during loading** — set the component's **KV Cache Initialization** to `Prefill`, or call **Prefill KV Cache** while the agent is idle. **Evict KV Cache** later to release only LLM context memory; the next **Send Message** restores it automatically. See [Manage an Agent's KV Cache](https://docs.tryllengine.com/v0.9/how-to/manage-agent-kv-cache.html).

**Save and load** — `ExportDialog` / `ImportDialog` are C++ only (the snapshot is not Blueprint-exposed). Store the canonical `TDLG` bytes in your own save file next to variables and game state. See [Save and Load Agent State](https://docs.tryllengine.com/v0.9/how-to/save-and-load-agent-state.html).
