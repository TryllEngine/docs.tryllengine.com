# Holds back, game tasks

Tryll game suites, one greedy pass

Only the game-task lines where no tool fits, such as small talk next to a door the player could open. A line counts when the model makes no call. A model that never calls anything scores full marks here, so read it beside Tool calls, game tasks.

*Every model on this page was measured on NVIDIA GeForce RTX 4080 · Vulkan.*
