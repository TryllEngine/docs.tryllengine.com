# Demos

Tryll ships two demo projects. Each one is a game project with ready-made agents that you can talk to in the editor and open in the graph editor.

| Project                                   | Engine                | Contents                                          |
| ----------------------------------------- | --------------------- | ------------------------------------------------- |
| [`TryllUnityDemo`](#unity-demo-project)   | Unity 6000.3 or later | A gallery of 11 agents, one workflow pattern each |
| [`TryllUnrealDemo`](#unreal-demo-project) | Unreal Engine 5.7     | The same gallery in Unreal, 10 agents             |

The release package for each engine holds the demo projects next to the plugin folder. Each demo loads the plugin from that folder, so a demo project must stay next to it. Each project's `README.md` says how to point it at the plugin if you move it.

In the tables below, **Nodes** lists the nodes in the order a turn reaches them. A slash separates the two routes after a branch.

## Unity demo project

**Open and run it.**

1. Add the `TryllUnityDemo` folder to Unity Hub and open it with Unity 6000.3 or later.
1. Set up the server and models as in [First Inference in Unity](https://docs.tryllengine.com/v0.10/getting-started/first-inference-unity.html).
1. Open `Assets/DemoScene.unity`. Each demo agent is a GameObject under **Agents** in the Hierarchy.
1. Open **Window → Tryll → Chat** and assign the agent's GameObject to **Agent Component**. See [Test an Agent in the Editor](https://docs.tryllengine.com/v0.10/how-to/test-agent-in-editor.html).

Each agent's GameObject has a **Scenario Note** component. In the Inspector it shows the pattern the agent demonstrates and the lines to type to test it. The workflow assets are in `Assets/Workflows/`. Every agent except Emotional Voice Character has a dialog script next to its workflow (`<Name>_Dialog.asset`) for the [Dialog Lab](https://docs.tryllengine.com/v0.10/how-to/compare-dialog-variants.html) (**Window → Tryll → Dialog Lab**).

The microphone in the voice demos works only in Play Mode. Aquarium Expert needs the embedding model BGE Small EN v1.5 downloaded first in **Window → Tryll → Model Manager**, because Tryll does not download embedding models for file-backed storages automatically.

## Unreal demo project

**Open and run it.**

1. Open `TryllUnrealDemo.uproject` with Unreal Engine 5.7. It is a C++ project, so the editor offers to build its modules on first open. The build needs Visual Studio with the C++ game development workload.
1. Set up the server and models as in [First Inference in Unreal](https://docs.tryllengine.com/v0.10/getting-started/first-inference-unreal.html).
1. The editor opens the map `M_Gallery`. It holds one actor per demo agent, named after the demo.
1. Open **Window → Tryll → Tryll Chat** and pick the demo's actor in **Actor**. See [Test an Agent in the Editor](https://docs.tryllengine.com/v0.10/how-to/test-agent-in-editor.html).

The workflows are in `Content/Workflows/` and the dialog scripts for the [Dialog Lab](https://docs.tryllengine.com/v0.10/how-to/compare-dialog-variants.html) (**Window → Tryll → Tryll Dialog Lab**) are in `Content/DialogScripts/`.

The gallery has the same agents as the [Unity demo project](#unity-demo-project), with the same characters and nodes, except Emotional Voice Character. Quest Giver and Aquarium Expert have one actor each.
