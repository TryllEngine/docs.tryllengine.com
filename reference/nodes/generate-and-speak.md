# Generate and Speak

The Generate-and-Speak node fuses LLM token generation with streaming [TTS](https://docs.tryllengine.com/reference/glossary.html#tts) synthesis: it runs the same projection and [language-model](https://docs.tryllengine.com/reference/glossary.html#language-model) inference as a [Generate](https://docs.tryllengine.com/reference/nodes/generate.html) node, but as tokens arrive it segments them into sentences, dispatches each sentence to a dedicated TTS strand, and emits PCM audio frames alongside the text deltas.

Because synthesis overlaps generation, audio begins after roughly the first sentence (`min_sentence_chars`) rather than after the whole answer — the TTS of one sentence runs while the LLM is still generating the next. This is the lowest-latency way to speak a generated answer (measured by the `time_to_first_audio_ms` diagnostic). Chaining a standalone [Generate](https://docs.tryllengine.com/reference/nodes/generate.html) → [Speak](https://docs.tryllengine.com/reference/nodes/speak.html) instead produces the *same* audio but cannot start until generation has fully finished, since `Speak` only sees the completed text. Prefer this fused node when you want a generated answer spoken with minimal delay, and the split form only when you need to branch on, inspect, or transform the text in between.

The voice is chosen by `tts_model_name`. Leave it empty to use the first TTS voice available in the server's model catalog, or set it to pick a specific voice.

`NodeType`: `GenerateAndSpeak`.

Leave `context_size` at `0` to inherit the model variant's window, then the server `default_n_ctx` (commonly 8192) — the same resolution as [Generate](https://docs.tryllengine.com/reference/nodes/generate.html). The `context` table is an advanced structural override. Do not set `q4_0` KV expecting a VRAM win at a right-sized window.

Each exit is a structural string field on the node's params; its value names the target node (empty = END).

## Constrained output (GBNF grammar)

Like [Generate](https://docs.tryllengine.com/reference/nodes/generate.html#constrained-output-gbnf-grammar), this node accepts an optional `grammar` (GBNF) that constrains the generated output at every decode step. The full rules there apply verbatim (must contain a `root` rule; fail-fast at agent creation and `InvalidParamValue` 3007 on a bad mutation; mutable per turn; constrain the wire, not the thinking).

The fit here is **narrower** than on Generate: the constrained output is also *spoken*, so grammar only makes sense when the constrained text is itself meant to be voiced — e.g. restricting an NPC to a fixed set of barks or canned lines:

```
root ::= "Halt!" | "Who goes there?" | "Move along." | "For the throne!"
```

Note the interaction with `min_sentence_chars` (default 12): very short constrained output may never cross the sentence-boundary threshold, so the whole (tiny) output flushes as a single TTS call — which is fine for barks.

See [Concept: Constrained output (GBNF)](https://docs.tryllengine.com/concepts/constrained-output.html) for what a grammar does and doesn't guarantee, and [How to constrain output with a grammar](https://docs.tryllengine.com/how-to/constrain-output-with-a-grammar.html) for a worked example.

## Diagnostics

When `enable_diagnostics = true`, this node contributes to `debug_info.nodes[].diagnostics`. See [Turn Diagnostics JSON](https://docs.tryllengine.com/reference/turn-diagnostics-json.html) for the envelope, the shared `input.prompt[]` shape, and the `engine` counters.

This is the only node that emits a fifth section, **`tts`** — the voice half of the fused step is kept separate from the language-model parameters.

| Key                                                                                                                                                                                            | Meaning                                                                                                                                                 | Absent when                                        |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| `parameters.model_name`                                                                                                                                                                        | The language model that actually ran, after fallback.                                                                                                   | The name could not be resolved.                    |
| `parameters.temperature`, `top_p`, `top_k`, `max_tokens`                                                                                                                                       | The resolved sampling set. Unlike [Generate](https://docs.tryllengine.com/reference/nodes/generate.html), the penalty and `seed` keys are not recorded. | —                                                  |
| `parameters.history_role`                                                                                                                                                                      | How the answer replays into later turns.                                                                                                                | —                                                  |
| `parameters.substitute_agent_variables`                                                                                                                                                        | `true`.                                                                                                                                                 | Output substitution is off.                        |
| `parameters.output_filter.strip_speaker_prefix`, `parameters.output_filter.strip_asterisk_spans`, `parameters.output_filter.strip_paren_spans`, `parameters.output_filter.strip_bracket_spans` | `true`, one key per enabled rule.                                                                                                                       | That rule is off.                                  |
| `parameters.output_filter.max_prefix_bytes`, `parameters.output_filter.max_span_bytes`                                                                                                         | The scan limits the filter ran with.                                                                                                                    | No filter rule is enabled.                         |
| `parameters.input`                                                                                                                                                                             | The configured input slot name.                                                                                                                         | Using the `user_message` default.                  |
| `parameters.output_name`                                                                                                                                                                       | The configured output slot name.                                                                                                                        | Defaulting to the node name.                       |
| `tts.speaker_id`, `speed`, `tts_lang`, `tts_voice`                                                                                                                                             | The voice settings the synthesis ran with.                                                                                                              | —                                                  |
| `tts.tts_voice_description`                                                                                                                                                                    | The voice description prompt.                                                                                                                           | Not set.                                           |
| `tts.tts_delivery_instruction`                                                                                                                                                                 | The delivery instruction.                                                                                                                               | Not set.                                           |
| `tts.sample_rate`                                                                                                                                                                              | The TTS model's native sample rate, in Hz.                                                                                                              | —                                                  |
| `tts.min_sentence_chars`                                                                                                                                                                       | Sentence-boundary threshold before a chunk is synthesized.                                                                                              | —                                                  |
